Settings

Folders

Changing the library or game user folder automatically moves your installed mods to the new location. A restart is needed afterward for the change to fully take effect (the real-time folder watcher keeps watching the old location until then).

Paths updated — restart SimsLink for the change to fully take effect.

Backups

Set via BACKUP_RETENTION_COUNT in .env — a replaced mod's oldest backups beyond this count are purged automatically.

Scan

Set via MODS_WATCHER_ENABLED in .env — catches mods added/removed outside SimsLink while it's running.

Recomputes every file hash — can take a while on large libraries.

Loose mods

Adopts .package/.ts4script files sitting directly at the root of Mods/ (no folder of their own) as individually-tracked mods, tagged "Loose" so they're easy to find afterward.

Custom groupings

Clears every manually corrected Library grouping label (the edit icon on an author-group header) — affected mods revert to normal author/prefix inference. Doesn't touch any mod's real "author" field.

Compatibility quarantine

Mods paused by the Library's "Incompatible mods" banner. Reactivate here once an update (checked via "Synchronize") fixes them — a mod still marked incompatible is left alone.

Logging

Set via LOG_LEVEL in .env (DEBUG/INFO/WARNING/ERROR/CRITICAL) — controls both the log file above and console output.

Blacklist

Local and manual only — flags installed mods whose name or id matches a pattern you've entered here. Never blocks anything by itself.
